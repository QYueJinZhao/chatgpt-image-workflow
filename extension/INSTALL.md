# ChatGPT 自动生图与下载助手：安装与使用

这是用于 ChatGPT 网页的第三方扩展，提供提示词队列、自动生图与下载、参考图、图库和批量管理，也兼容 Gemini。扩展不隶属于 OpenAI 或 Google；账号、模型、图片生成权限和额度由对应站点提供。

## 安装

商店条目正式发布后，可从真实条目安装并由 Chrome 管理更新。当前 ZIP 可用于手动安装，不代表已通过商店审核。

1. 将完整 ZIP 解压到自己选择的普通文件夹，保留该文件夹。根部应能看到 `manifest.json`。
2. 打开 Chrome 的扩展管理页，开启开发者模式，选择“加载已解压的扩展程序”，选中刚解压的文件夹。不要选择 ZIP 文件或它的父文件夹。
3. 打开或刷新 ChatGPT / Gemini 网页。点击工具栏里的扩展图标可展开或收起面板。

基础功能不需要源码仓库、Node.js、本机服务或配对文件。最低 Chrome 版本为 116。手动更新时先备份，再将新 ZIP 解压到原扩展文件夹，重新加载扩展并刷新已打开的网站标签页；页脚和设置页应显示当前运行版本。

## 自动生图与下载

1. 登录支持图片生成的 ChatGPT 账号，打开目标会话。先确保该站点当前账号和模式可以正常生图。
2. 点击“新建任务”，填写提示词，多项默认用空行分隔；在生成参数中可切换为逐行分隔。需要图生图时，在“参考图”中添加并选中图片。
3. 点击“加入队列”，检查任务后点击“开始队列”。面板按队列逐项提交、等待结果并下载。运行期间保留页面打开，避免同时手工发送消息。
4. 在底部“设置”的浏览器下载区域配置子目录即可。文件保存到 Chrome 下载设置指定的位置，不要求连接任何本机服务。
5. 在图库查看原始归档、描述、筛选、四种视图和批量下载；面板“布局”可切换嵌入/悬浮和调整宽度。展开状态、宽度与布局会自动保存。

生成能力和等待时间由站点决定；遇到登录、验证码或额度限制时按站点提示处理。下载保存页面可取得的图片字节，不承诺等同于站点“完整尺寸”下载。Gemini 的支持同样取决于当前账号、模式及网页结构。

## 可选本机增强

仅在需要任意 Windows 图片目录、SQLite 创作记录、下载通知或 MCP 客户端调用时使用。

公开 ZIP 不包含配套服务程序、私有密钥或默认配对文件。需要单独安装兼容的本机服务；当前配套服务要求 Node.js 22.13 或更高版本。为当前安装的扩展生成 JSON 配对文件，在设置的“本机增强服务 → 配对连接”中选择文件，再点击“连接本机增强”，按 Chrome 提示允许本机访问。不要使用其他电脑或其他扩展的配对文件。

默认端口仅用于本机安装约定，实际连接端口由配对文件决定。关闭本机增强后，浏览器生图、图库和浏览器下载仍可使用。Windows 自选目录只接受已有的普通图片文件夹；本机服务不会随扩展自动安装。

Webhook 默认关闭，仅在用户配置并启用后发送以后成功下载的通知。SQLite 和本机下载文件不包含在浏览器工作区备份中，应单独保管。

## 恢复、备份与隐私

暂停、刷新或关闭页面后，已提交且结果不明确的任务进入“待核对”，不会自动重新提交；先核对对应会话再决定后续操作。

工作区 ZIP 包含图片、提示词和已归档会话，恢复是追加导入，不会自动开始生成；备份不加密。更换安装方式或卸载前先导出备份，避免因扩展身份变化或卸载丢失浏览器内数据。会话归档只包含当前已加载的内容。
