# 数据与权限

适用于“ChatGPT 自动生图与下载助手”。扩展是第三方工具，不隶属于 OpenAI 或 Google。

- 队列与显示偏好保存在扩展 chrome.storage.local，原图、参考图和会话保存在 IndexedDB。无遥测、广告、远程脚本或外部字体。
- 扩展仅在两个 ChatGPT origin 及精确 Gemini origin 操作已有输入框、当前已加载消息和图片；按站点校验图片资源。不会读取网站cookie、认证令牌或私有账户API。
- 用户明确启动队列后，提示词和所选参考图通过当前站点网页正常提交给该站点，用于用户请求的图片/文字生成；站点自身的数据处理遵循其政策。扩展不内置生成模型或第三方图片 API，不把队列内容发送至开发者服务器。
- Chrome下载仅管理本扩展登记的ID，不更改其他来源文件。指定本机图片目录时，经已配对的本机服务保存经SHA验证的原始字节，冲突编号，不覆盖已有文件。ZIP/会话导出仍用Chrome。
- 设置使用扩展源iframe，宿主网站不能读取输入；只公开options.html页面壳，未公开私有配对。关闭设置会清空未提交Webhook地址并销毁frame。
- 本机服务仅监听127.0.0.1，校验扩展origin、Host和配对密钥。配对文件不打印、不打包或提交；当前服务不读取或消费Open WebUI授权。独立历史连接器保持原授权边界。
- SQLite记录图片名称、描述、提示词、来源、日期、下载和通知结果，保存在服务数据目录。原图不写入SQLite。离线归档不等于已写SQLite，待补录状态与通知状态单独显示。
- Webhook默认为关闭。显式开启后只向用户配置地址发送以后成功下载的JSON事件，默认不含图片、绝对路径、提示词、描述或会话链接；明确勾选才附带提示词和描述。更换地址不会把旧队列发到新接收端。
- Webhook URL可能含私密签名，只存本机SQLite、不回填、不给内容脚本、不记录日志或工作区ZIP。数据库含私人资料和该地址，请妥善保管。接收端需按eventId去重，未知通知仅手动重试。
- 知识库同步、上传对账、图库凭据配置及当前MCP入库/检索工具已退役；不读取旧凭据或删除已有知识库与历史图片。
- 工作区ZIP含会话、提示词和原图，不含SQLite、Webhook配置或配对密钥；ZIP不加密。卸载扩展会清除扩展数据，请先备份；数据库和本机下载文件需单独保管。
